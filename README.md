# Fallacy Detection in User-Generated Argumentative Content

Research on identifying fallacies in argumentative text written by ordinary people online,
carried out during a research internship at the [UKP Lab](https://www.informatik.tu-darmstadt.de/ukp/),
TU Darmstadt, in 2015.

## The question

Argumentation theory names and classifies fallacies with some precision, but user-generated
text rarely arrives in that shape. The work asked what has to happen for a theoretical notion
to become something a model can learn: which distinctions survive contact with real data,
which annotations can be trusted, and what a usable ground truth would look like.
